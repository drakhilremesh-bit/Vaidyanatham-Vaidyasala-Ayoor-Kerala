VAIDYANATHAM HERBALS — LIVE WEBSITE PACKAGE

Files:
- index.html
- styles.css
- assets/js/app.js
- assets/images/ (10 image assets)

Run locally:
1. Extract the ZIP.
2. Open a terminal in the extracted folder.
3. Run: python -m http.server 8000
4. Visit: http://localhost:8000

GitHub Pages:
1. Upload the complete folder contents to the repository root.
2. Keep all paths unchanged.
3. In Settings > Pages, select Deploy from a branch, branch main, folder /(root).
4. Save and wait for deployment.

Note:
- This site uses WhatsApp for consultation/order enquiries; it does not include a server-side booking/payment backend.
- The product image health-mix-lehya.jpg is not included in the uploaded assets; the page may show its built-in fallback.

Loading-screen fix: the opening screen now dismisses after DOM readiness and has an independent 2.2-second watchdog. It does not wait for third-party scripts or the window load event.
